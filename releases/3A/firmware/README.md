# Option 3A firmware

`CraftBridge_Motor_Node_Web_v1_0_0/` is the released Motor Node A/Web Arduino sketch from firmware baseline `06e6ab66588173c0f9072d2bfa5940969a2d0ba6`.

The sketch folder and `.ino` file retain the same name so Arduino IDE treats the package correctly. `../platformio.ini` builds the same source files with the pinned ESP32-S3 configuration.
