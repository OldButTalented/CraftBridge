# Option 3A hardware status

Options 3A, 3B and 3C will use the same shared hardware platform. The hardware design is still under development and is not part of this firmware/software release.

Validated schematic, PCB, CAD, BOM and production files will be released later. No hardware source is inferred, generated or copied from unfinished development work for this release.

The future open-hardware package will use standard manufacturing outputs and will not require a specific PCB manufacturer.
